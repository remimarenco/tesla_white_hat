## Generation Overview

### First Generation Model S (2012-2016)
The original Model S went through several significant updates:

#### 2013-2014 (Early Models)
- **MCU**: MCU1 (NVIDIA Tegra 3)
- **Autopilot**: Not available
- **Battery Options**: 60kWh, 85kWh
- **Motor**: Single motor RWD or Performance

#### 2014-2016 (Mid-cycle Updates)
- **MCU**: MCU1
- **Autopilot**: Autopilot 1.0 hardware introduced (Oct 2014)
- **Battery Options**: 70kWh, 85kWh, 90kWh
- **Motor**: Dual motor AWD option added

#### 2016-2017 (Late First Gen)
- **MCU**: MCU1 (some late models)
- **Autopilot**: AP1 (2014-2016) or AP2 (late 2016+)
- **Battery Options**: 75kWh, 90kWh, 100kWh
- **Motor**: Dual motor AWD, Performance variants

## Why 2013-2017 Model S?

### Research Value

1. **Legacy Systems**: Earlier generations use different architectures
2. **Hardware Evolution**: Multiple hardware iterations to compare
3. **MCU1 Platform**: Different from newer MCU2/MCU3 systems
4. **Autopilot Evolution**: Can study AP1 vs AP2 transition
5. **Community Knowledge**: Extensive documentation available
6. **Upgrade Paths**: Understanding retrofit capabilities

### Known Characteristics

#### MCU1 Platform
- NVIDIA Tegra 3 based
- 17-inch touchscreen
- Slower performance compared to MCU2/3
- Limited update support (as of 2024)
- Potential upgrade path to MCU2

#### CAN Bus Architecture
- Earlier CAN bus implementation
- Different from Model 3/Y architecture
- More accessible diagnostic interfaces
- Well-documented by community

## Safety Considerations

⚠️ **IMPORTANT**: Model S vehicles have larger battery packs and higher voltage systems

- High-voltage safety training recommended
- Never work on HV systems without proper training
- Use insulated tools rated for HV work
- Understand emergency disconnect procedures
- Be aware of older safety mechanisms vs. Model 3
